# Security Policy — NurseCalc Pro

## 1. Supported Versions

We release security patches and updates for the following active version branches:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 2. Clinical Mathematical Integrity & Safe Harbor

NurseCalc Pro operates on strict clinical mathematics safety guidelines:
1. **Deterministic Execution**: Mathematical formulas for medication calculations (Heparin, IV drip, insulin, pediatric dosing) are strictly deterministic and never generated by generative AI models.
2. **ISMP Compliance**: Zero tolerance for trailing zeros (`5.0` is strictly forbidden and normalized to `5`), and mandatory leading zeros (`.5` is strictly forbidden and normalized to `0.5`).
3. **Single-Site Injection Ceilings**: Injections > 3 mL trigger clinical capacity warnings.

---

## 3. Reporting a Vulnerability

If you discover a security vulnerability or a mathematical calculation discrepancy:

1. **Do NOT open a public GitHub issue.**
2. Send an email to `security@nursecalc.local` or contact the repository maintainer directly.
3. Include detailed steps to reproduce the issue, including:
   - Input values used in calculation or API endpoint
   - Expected output vs actual output
   - Relevant HTTP request/response headers
   - Potential clinical safety impact

We strive to acknowledge reports within **48 hours** and provide a patched release within **7 business days**.

---

## 4. Educational Disclaimer

NurseCalc Pro is designed for educational, simulation, and NCLEX-RN preparation purposes only. It is not intended for real-time patient diagnosis or unauthorized clinical drug administration.
